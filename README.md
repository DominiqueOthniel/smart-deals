# Smart Deals Cameroon

E-shop for phones and laptops. Brand colors are navy blue and gold, with a golden Africa logo.

## Open the site

Double-click `index.html` in this folder.

Or start a local server with Python:

```
python -m http.server 5173
```

Then visit http://localhost:5173

## What is included

- Home, shop, product, cart, checkout, about, contact
- Prices in FCFA
- Delivery cities across Cameroon
- MTN MoMo, Orange Money, cash on delivery
- English and French switch
- WhatsApp button (update the number in `assets/js/main.js`)

## Change your WhatsApp number

In `assets/js/main.js`, edit `WHATSAPP` (format `2376XXXXXXXX`).
